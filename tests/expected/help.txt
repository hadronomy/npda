cc 0.2.0
Simulate deterministic Turing machines.

Usage: cc [OPTIONS] COMMAND

OPTIONS
-------
  -help, --help    Show this help

COMMANDS
--------
  turing     Run a Turing machine on input strings, or draw it
  explain    Say what an error code means and how to fix it

EXAMPLES
--------
  $ cc turing -config examples/turing/anbm.turing aabb abb
  $ cc turing -config examples/turing/anbm.turing -trace-view compact aabb
  $ cc explain E0007
